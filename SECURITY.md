# Security Policy

CYBER-OS includes tools that kill processes, read local browser databases, and run a local web server for the camera cockpit, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Instead use GitHub's private reporting:
**[Report a vulnerability](https://github.com/abhisek11/cyber-os-terminal/security/advisories/new)**.

Include the affected command or file, steps to reproduce, and the impact. You should get a reply within a few days. Once a fix is released you will be credited in the advisory unless you prefer otherwise.

## Supported versions

Only the latest commit on `main` receives fixes.
